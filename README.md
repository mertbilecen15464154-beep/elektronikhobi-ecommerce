# elektronikhobi-ecommerce
Custom E-Commerce storefront UI built with Tailwind CSS &amp; JavaScript.
# 🛒 ElektronikHobi - Modern E-Ticaret Arayüzü

Elektronik bileşenler, hobi ürünleri ve yazılım/donanım araçları için geliştirilmiş modern, hızlı ve duyarlı (responsive) e-ticaret vitrini ve ürün sergileme platformu.

---

## ✨ Öne Çıkan Özellikler

- 📦 **Ürün Kataloğu & Filtreleme:** Kategoriye göre dinamik ürün listeleme ve arama.
- 🛒 **Sepet Yönetimi:** Kullanıcı dostu dinamik sepet arayüzü ve tutar hesaplama.
- 📱 **Tam Mobil Uyumluluk:** Mobil, tablet ve masaüstü cihazlara özel Tailwind CSS düzeni.
- ⚡ **Hızlı ve Akıcı Arayüz:** Modern JavaScript ile minimize edilmiş sayfa yüklenme süreleri.

---

## 🛠️ Kullanılan Teknolojiler

- **Frontend:** HTML5, Tailwind CSS, JavaScript (ES6+)
- **UI & Icons:** Font Awesome / Google Fonts
